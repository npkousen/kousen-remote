Privacy Policy

Kousen Remote keeps remote setup data on your own Linux device.

This policy applies to Kousen Remote, the open-source Linux input service and public documentation page published from this repository.

Last updated: August 21, 2026

1. Information The Project Handles

Kousen Remote may handle local setup details such as Bluetooth device addresses, BlueZ object paths, paired-device metadata, GATT characteristic identifiers, action mappings, service configuration values, and local diagnostic logs.

2. Local Device Storage

The command-line tools and systemd installer write configuration and logs on the Linux device where Kousen Remote runs. These can include the selected remote address, mapping path, reconnect settings, service status, and journal output.

This data stays on your device unless you choose to copy, back up, publish, or share it. Avoid committing private Bluetooth addresses, hostnames, logs, SSH keys, tokens, or personal network notes to a public repository.

3. Bluetooth and Operating System Data

Pairing, trust, connection state, and Bluetooth credentials are managed by the host operating system and BlueZ. Kousen Remote uses BlueZ through D-Bus but does not provide a hosted account system for storing Bluetooth pairing data.

4. No Kousen Remote Accounts or Backend

Kousen Remote does not require user accounts and does not include its own hosted backend database for collecting remote-control setup information. The public documentation page does not receive, store, or manage your local service configuration through the project itself.

5. Diagnostic Output

Diagnostic commands such as scan, devices, info, gatt, and gatt-notify may display hardware identifiers, Bluetooth addresses, raw report values, timestamps, and connection details in your terminal. Treat that output as local diagnostic information.

6. Kiosk, Browser, and App Links

Kousen Remote emits Linux input events. Apps that receive those events, such as Chromium, KousenTV, VLC, Plex, CommandCenter, or third-party websites, may handle data according to their own privacy policies and browser behavior.

7. Hosting and Technical Logs

When the public documentation page is hosted, the hosting provider may process standard technical request data needed to deliver the page, such as IP address, browser details, timestamps, requested paths, and basic server or CDN logs.

8. Cookies, Analytics, and Tracking

Kousen Remote does not intentionally include advertising trackers, analytics dashboards, or behavioral profiling tools. Essential browser and hosting mechanisms may still be used to load static files securely and reliably.

9. Data Security

Because configuration and diagnostic data are generally stored on your own Linux device, protecting local admin access, SSH access, systemd configuration, BlueZ pairing data, and terminal logs is important.

10. Children's Privacy

Kousen Remote is not directed to children under 13, and the public documentation page does not knowingly collect personal information from children through Kousen Remote's local-first tools.

11. Changes to This Policy

This Privacy Policy may be updated from time to time. The revised version will be posted on this page with a new "Last updated" date.
